## Funcionalidades recientes

### Exportación de Orden de Servicio Detallada
- **Ruta de acceso**: `Órdenes de servicio → Exportar Orden de Servicio`.
- Permite ingresar el ID de una orden de servicio, consultar sus datos completos (servicio, cliente, vehículo y repuestos utilizados) y generar un archivo de texto `orden_servicio_<ID>.txt` en la raíz del proyecto con el desglose de repuestos, mano de obra y total a pagar.
- Si el ID no existe o no es válido, muestra un mensaje amigable en consola.
